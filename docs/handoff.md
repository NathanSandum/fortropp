## The system in one page

- **frontend/**: SvelteKit; e2e in `tests/e2e` (Playwright maps `*.fortropp.test` to loopback).
- **infra/**: compose stacks, Caddy, PowerDNS, `test-services` (fake Cloudflare, e2e echo upstream), `tofu/`.

## How to verify

- Inner loop: `just test-quick` (no stack, no e2e: backend tests, proofs, test-services, frontend unit tests).
- E2e runs in two phases (2026-10-30): everything not tagged `@exclusive` in parallel with 2 workers (`playwright.config.ts`; measured 6.0 min against 12–13.6 serial; 4 workers gave 4.9 min with one load-looking failure, so 2 was chosen), then the `@exclusive` tests alone with 1 worker. `@exclusive` marks tests that need the stack to themselves: the ones flipping a global fake switch (Cloudflare `setOutage`, Postmark `setFailure`) and the folder-upload stress test. A new test that touches global fake state or loads the whole stack must carry the tag.
- Everything: `just test` (stack + both e2e phases). Run in the background as `just test > <scratchpad>/x.log 2>&1; echo exit=$?` and read the recorded `exit=` line. It now tears the test stack down at the end.
- Worker: `cd worker && cargo test --workspace`, `just worker::lint`, `just worker::proofs`.
- Fake Cloudflare: `just test-services` (clippy + contract tests).
- Real-API tests: `just backend::test-r2` and `just backend::test-hostnames` (the user runs them; `op run` with `backend/api-tests.env.tpl`).

## Gotchas

- After a backend `query!` change, run `just sqlx-prepare` in `backend/` (Docker, port 5432 free). It can race Postgres startup ("unexpected response from SSLRequest"); just rerun it.
- `just test` starts with `dev-down` (keeps dev data); `just dev-up` afterwards. A sleeping laptop stalls it: `just test-down` and rerun.
- Don't edit worker, `site-config` or backend sources while `just test` is building images.
- Dev `.test` names: `/etc/resolver/test` on the user's Mac → dev PowerDNS `127.0.0.1:5300`; `just dev-domain <zone>`, `just dev-proof <zone> <hostname> <token>`; Caddy issues on-demand certs only for `.test`.
- Rebuilding the frontend while dev runs: `docker compose -f infra/docker-compose.yml restart caddy`.
- Known flakes under load: `password_reset.e2e.ts`; wrangler's ProxyWorker "Network connection lost" (500 on one request). Rerun alone.
- Run the full suite with the machine idle, under `caffeinate -i`. Sign-up 502/503s and cut-off response bodies appeared only while the Mac was in use (2026-11-18). Docker Desktop has about 6.8 GB of RAM, and Postgres crashed once under memory pressure; low disk space made it worse.
- A refreshed `db-traffic.txt` needs a fully passing `npm run test:e2e`; a run with any failure leaves it untouched. Single-file runs with `DB_TRAFFIC_SNAPSHOT=1` overwrite it with partial counts, so restore it from git afterwards.
- Demo mode is a per-tab `sessionStorage` flag set only by `/demo/`. A tab opened any other way talks to the real backend, which answers 502 when the dev stack is down.
- Playwright's request client uppercases HTTP methods; Miniflare turns `Upgrade: websocket` into a handshake `GET`; Local Explorer only accepts `Host: localhost`.
- No secret lives in a local file anymore: 1Password vault `fortropp` holds `tofu` (OpenTofu roots, worker deploy token) and `backend-api-tests` (real-API test credentials: an R2 pair scoped to the OpenTofu-managed bucket `fortropp-test`, 1-day object expiry, and the hostnames token). Builds need no `.env` (`backend/.cargo/config.toml` sets `SQLX_OFFLINE`). Done 2026-10-26: the leaked broad token is revoked, the old `fortropp` bucket and KV namespace `57952bbe…` are deleted. The hostnames test token must stay separate from production's.
- zsh doesn't word-split `$VAR` holding a command; write commands out.
