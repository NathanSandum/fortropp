When iterating on visual designs (logo work, 2026-10-28):
- Don't describe abstract features as emotions ("happy eyes", "sleepy"); user sees them as forms.
- Don't push a speculative theory as a fix; when the user's complaint is ambiguous ("face edge goes over the beard"), ask which part they mean before changing geometry.
- Define the silhouette first, then add texture (e.g. cloud puffs generated along a base curve), not texture-as-shape.

**Why:** a mis-read complaint produced a rejected variant ("bad theory, discard it"), and emotion-labelling was explicitly corrected.
**How to apply:** for each design round, change only what was asked, and name ambiguities as a question. Relates to [[project-viking-logo]].
